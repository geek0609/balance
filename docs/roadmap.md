# Roadmap

1. Define accounting workflows and data import requirements using sample data.
2. Build a Windows accounting foundation: companies, ledgers, balanced vouchers, and basic reports.
3. Implement import of a verified export format with explicit unsupported-field handling.
4. Expand iteratively into inventory, invoicing, tax, reporting, and integrations as requirements are verified.

Use disposable sample data while the project is under development.
